# Public data sources and evidentiary roles

| Resource | Data type | Use in the V1.6 scientific narrative | Limits | Link |
|---|---|---|---|---|
| GBM-Space | Pathology-annotated Visium spatial transcriptomics | Primary discovery of IT–CT tissue-level programs (17 eligible sections; 4 donors) | Spot-level multi-cell expression; small donor count | https://www.gbmspace.org/ |
| GBM-Space (same atlas, distinct layer) | snRNA-seq | Endothelial states (2,241 nuclei; 12 donors) | Not an independent external cohort; no spot-to-nucleus direct pairing | https://www.gbmspace.org/ |
| GSE162631 | Patient-paired core/periphery endothelial scRNA-seq | Complementary external endothelial remodeling | Core/periphery not identical to IT/CT pathology | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE162631 |
| Ivy GAP / GSE107559 | Histopathology-guided regional bulk RNA-seq | Complementary anatomical regional comparison | Bulk regions do not establish cell-of-origin | https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE107559 |
| Sonpatki Xenium S2/S6 | Targeted in situ spatial transcripts | Cross-technology localization checks (including CAV1 and PLVAP) | Variable label coverage / segmentation; limited panel; S2 and S6 differ | https://doi.org/10.5281/zenodo.17622242 |

These are not four independent experiments measuring the same primary endpoint. GSE131928 supported an older malignant-state/pseudotime analysis in V1.5; that branch is outside this V1.6 findings release.

**Access/rights:** This repository contains summaries and pointers to publicly hosted source data, not copies of raw participant-level or third-party assay files. Consult each originating study for data access, citation, consent and licensing conditions.
